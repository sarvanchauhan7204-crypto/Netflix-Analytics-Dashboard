# Netflix Content Analysis & Data Visualization

## 📌 Project Overview
This project focuses on analyzing Netflix Movies and TV Shows to understand content distribution, audience ratings, release trends, and the overall composition of the Netflix library. The project uses data analysis and visualization techniques to transform raw data into meaningful insights.

## 🎯 Project Objectives
- Analyze the distribution of Movies and TV Shows.
- Explore content ratings and rating categories.
- Identify trends in content releases over time.
- Compare different content categories and their representation.
- Present findings through clear and effective visualizations.
